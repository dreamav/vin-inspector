#### Шаг 3: Скрипт распознавания `recognize_vin.py`
Скрипт реализован в [ocr/recognize_vin.py](file:///e:/vibecoding/vincode/ocr/recognize_vin.py) и снабжён удобной корневой точкой входа [recognize_vin.py](file:///e:/vibecoding/vincode/recognize_vin.py).

**Пайплайн работы:**
1. **Предобработка OpenCV:**
   - Безопасная загрузка через `np.fromfile` + `cv2.imdecode` (полная поддержка любых Unicode/кириллических путей в Windows).
   - Динамическое масштабирование: сжатие огромных картинок (>1920px) для быстродействия и апскейл мелких кропов (<900px) для повышения читаемости текста.
   - Grayscale + CLAHE (Contrast Limited Adaptive Histogram Equalization) для выравнивания контраста и нейтрализации бликов.
   - Маска нерезкого маскирования (Unsharp Mask) для рельефного текста на металле.
2. **Инференс EasyOCR:**
   - Запуск `easyocr.Reader(['en'], gpu=False, verbose=False)`.
   - Определение текстовых блоков с координатами и уверенностью (confidence).
3. **Постобработка по стандарту ISO 3779:**
   - Нормализация запрещённых символов: `O` -> `0`, `I` -> `1`, `Q` -> `0`.
   - Очистка от пробелов, дефисов, кавычек, звёздочек и мусора.
   - Фильтрация фрагментов общего английского текста (отсечение фраз сертификации типа `"DATE OF MANUFACTURE"`, у которых последние 4 символа состоят из букв, в отличие от реальных серийных номеров VIS).
4. **Валидация контрольного знака (Modulo-11 Check Digit):**
   - Расчёт весовых коэффициентов `[8, 7, 6, 5, 4, 3, 2, 10, 0, 9, 8, 7, 6, 5, 4, 3, 2]`.
   - Буквенно-числовая транслитерация (A=1...H=8, J=1...N=5, P=7, R=9, S=2...Z=9).
   - **Умное восстановление визуальных OCR-ошибок (Check-Digit Guided Correction):** если OCR путает визуально похожие символы (`S` <-> `5`, `Z` <-> `2`, `B` <-> `8`, `G` <-> `6`), скрипт тестирует комбинации замен и, найдя математическое совпадение контрольного знака Modulo-11, автоматически восстанавливает точный VIN.
5. **Чистый JSON в `stdout`:**
   - Никаких лишних логов в `stdout`, что позволяет вызывать скрипт напрямую из PHP через `shell_exec` / `exec` и парсить через `json_decode`.

#### Шаг 4: UI модалка сканирования и веб-камера (Vue 2 + PHP API)
1. **Интерфейс сканирования:**
   - В компоненте `VinSearch.vue` напротив поля ввода VIN добавлена кнопка **«📷 Скан»**.
   - Создан компонент `VinCameraModal.vue` с поддержкой видеопотока веб-камеры (`navigator.mediaDevices.getUserMedia`), визирной рамкой и лазерной анимацией сканирования.
   - Поддерживается альтернативный режим загрузки через выбор файла и Drag & Drop.
2. **Бэкенд-эндпоинт `api/recognize-vin.php`:**
   - Принимает загруженное фото или снимок кадра с холста веб-камеры.
   - Сохраняет временный файл в `ocr/tmp_images/`.
   - Запускает Python OCR скрипт.
   - **Автоматическая очистка диска:** временный файл немедленно удаляется (`@unlink`) сразу после выполнения OCR.
   - Возвращает распознанный 17-значный VIN в JSON формате.
3. **Автоподстановка в форму:**
   - Распознанный VIN вставляется в поле ввода с бейджем валидности контрольного знака.
   - Автоматически запускается декодирование через базу NHTSA.
