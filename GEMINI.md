# Правила проекта (VIN Inspector)

## 1. Выполнение команд в терминале
- **Команда PHP (Строго короткая):** Интерпретатор PHP 7.1 уже добавлен в системный PATH Windows (`D:\OpenServer\modules\php\PHP-7.1\php.exe`). ВСЕГДА запускать команды ИСКЛЮЧИТЕЛЬНО через короткое имя `php` (например: `php <файл>.php` или `php -S localhost:8000`). Категорически запрещено использовать длинные пути вида `& "D:\OpenServer\..."`.
- **Автономный запуск команд:** Команды `php *`, `curl.exe *`, `npm *`, `git *` запускать СРАЗУ и самостоятельно, без предварительных вопросов и переспрашиваний в чате.
- **Запрет на проверку портов:** СТРОГО ЗАПРЕЩЕНО вызывать `Get-NetTCPConnection`, `Test-NetConnection` или `netstat` перед запуском серверов. Никакой лишней самодеятельности в терминале — сразу поднимай сервер!
- **Серверы разработки (фоновые процессы / IsDaemon):**
  - Бэкенд: `php -S localhost:8000` в корне проекта (`d:\vibecoding\vincode`).
  - Фронтенд: `npm run dev` в папке `frontend` (порт 3000, прокси на 8000).
- **Особенности PowerShell на Windows:** Не выполнять inline-команды `php -r "$...;"` (так как символ `$` перехватывается PowerShell). Вместо этого создавать временный php-файл, выполнять через `php <файл>.php` и удалять после теста.

## 2. Стек и архитектура фронтенда
- **Фреймворк:** Исключительно **Vue 2** с использованием **Options API** (`data`, `methods`, `computed`, `watch`, стандартный жизненный цикл).
- **Стилизация:** Чистый **Vanilla CSS** внутри тегов `<style scoped>` каждого Single-File Component (`.vue`). Не устанавливать TailwindCSS или тяжелые сторонние UI-фреймворки (Vuetify, Element UI и т.д.), чтобы код оставался легким, понятным и полностью контролируемым.
- **Дизайн:** Современный темный интерфейс (glassmorphism, аккуратные скругления, микро-анимации, цветовая индикация статусов).

## 3. Стек и архитектура бэкенда
- **Язык:** Чистый **PHP 7.1** без сторонних пакетов Composer (без Guzzle, Symfony и т.п.).
- **HTTP-запросы:** Использовать стандартный встроенный модуль `cURL` с поддержкой gzip-декомпрессии (`CURLOPT_ENCODING => ''`) и передачей необходимых заголовков (`Origin`, `Referer`, `Site`, `X-Site`).
- **Конфигурация марок:** Все поддерживаемые марки и их целевые сайты хранятся в едином файле `config/brands.json`. Логика бэкенда и фронтенда должна динамически подтягивать настройки из этого файла через `api/config.php` и `api/get-brands.php`.

## 4. Чистота репозитория
- Не оставлять в корне проекта временных отладочных скриптов после завершения задачи.
- Сохранять читаемость и комментирование на русском языке.

## 5. Git и GitHub
- **Аккаунт GitHub:** `dreamav` (шаблон удалённых репозиториев: `https://github.com/dreamav/<имя_проекта>.git`).
- **Основная ветка:** `main` (переименовывать `master` в `main` при инициализации).
- **Учётные данные:** Авторизация на `github.com` сохранена в Windows Credential Manager (`manager-core`). Git выполняет `push`/`fetch` без повторного запроса пароля.
- **Ветвление фичей (Feature Branches):** Любые крупные экспериментальные фичи, интеграции новых сторонних библиотек (ML, OCR, внешние сервисы) или нестандартные доработки ВСЕГДА начинать с создания отдельной ветки `feature/<имя>`. Ветка `main` остаётся строго стабильной для продакшна. Вливать изменения в `main` только после подтверждения стабильности.
- **Автоматический коммит (Zero-Friction):** Сразу после нажатия пользователем кнопки Accept, одобрения изменений или перехода к следующему шагу АВТОМАТИЧЕСКИ выполнять `git commit` без повторных переспрашиваний подтверждения в чате. Сообщения коммитов формировать информативными в формате Conventional Commits.

- Для стрелок, шагов и переходов использовать исключительно обычные символы: `->`, `-->` или `>`.

## 5. Горячие триггер-фразы синхронизации (Chrome Tabs)
1. **"export chrome tabs"**:
   - Автоматически экспортировать текущую сессию Chrome (окна, цветные группы, вкладки) в `.agents/session_backup.json` командой `php .agents/scripts/chrome_session.php export`.
   - Закоммитить и запушить: `git add .agents/session_backup.json .agents/tab_rules.json && git commit -m "Auto-sync chrome session" && git push`.
   - Вывести краткий отчёт: сколько окон, групп и вкладок сохранено и отправлено в репозиторий.
2. **"import chrome tabs"**:
   - Выполнить `git pull` для получения актуального слепка сессии.
   - Восстановить окна и группы на текущей машине командой `php .agents/scripts/chrome_session.php restore`.
   - Вывести отчёт о восстановленных окнах и вкладках.
